# 아키텍처 결정 기록

이 디렉터리는 프로젝트에 장기간 영향을 주는 비가역적이거나 변경 비용이 큰 결정을 기록한다. 개별 실행에서 AI가 내린 판단은 ADR이 아니라 `docs/decision-records.md`의 형식을 따른다.

## 파일 이름

ADR은 순번과 kebab-case 제목을 사용한다.

```text
0001-code-owned-control-flow.md
0002-append-only-run-events.md
```

## 권장 구성

- 상태: 제안, 승인, 대체, 폐기
- 맥락: 왜 결정이 필요한가
- 결정: 무엇을 선택했는가
- 대안: 어떤 선택지를 검토했는가
- 근거: 왜 이 대안을 선택했는가
- 결과: 장점, 단점, 위험과 후속 작업
- 관련 문서와 코드

이미 코드에 반영된 결정을 문서화할 때도 당시의 의도를 추측하지 않는다. 근거가 불분명하면 열린 질문으로 남기고 사용자에게 확인한다.

# 기능 명세

이 디렉터리는 구현할 기능의 목표, 범위, 동작과 완료 조건을 기록한다. 현재는 임시 뼈대이며 첫 문서로 `normal-and-night-modes.md`를 작성할 예정이다.

## 권장 구성

각 기능 명세는 다음 내용을 포함한다.

1. 문제와 사용자 가치
2. 목표와 제외 범위
3. 사용자 시나리오
4. 기능 요구사항
5. 실패 및 에스컬레이션 동작
6. 관측·판단 기록 요구사항
7. 완료 조건과 검증 방법
8. 열린 질문

파일 이름은 기능을 나타내는 소문자 kebab-case를 사용한다.

```text
normal-and-night-modes.md
resume-run.md
```

구현을 시작하기 전에 열린 질문이 결과를 크게 바꿀 수 있는지 확인하고, 필요한 결정은 사용자에게 먼저 질문한다.

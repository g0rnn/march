# 프로젝트 문서

이 디렉터리는 `march`의 설계, 기능 명세, 결정 근거, 판단 기록과 부채를 관리한다. 현재는 다음 작업 세션을 위한 임시 구조이며, 각 문서는 코드와 함께 점진적으로 작성한다.

## 구조

```text
docs/
├── README.md
├── architecture.md          # 시스템 구조와 데이터 흐름
├── decision-records.md      # 실행 중 AI 판단 기록 규칙
├── specs/                   # 기능별 요구사항과 완료 조건
├── adr/                     # 장기적인 아키텍처 결정
└── debt/                    # 기술·인지·의도 부채
```

## 작성 원칙

- 문서는 한국어로 작성하고 코드 식별자와 파일 이름은 영어를 사용한다.
- 현재 사실, 앞으로의 목표, 검토 중인 아이디어를 구분한다.
- 코드에서 확인할 수 있는 사실을 불필요하게 복사하지 않고 의도와 제약을 중심으로 기록한다.
- 하나의 문서에는 하나의 명확한 목적을 둔다.
- 동작이 바뀌면 관련 문서가 여전히 정확한지 함께 확인한다.

## 다른 루트 문서

- `AGENTS.md`: AI 에이전트 작업 규칙
- `CONTEXT.md`: 제품 맥락과 성공 기준
- `BACKLOG.md`: 다음 작업과 미결정 사항
- `UBIQUITOUS_LANGUAGE.md`: 공통 용어
- `SECURITY.md`: 안전 및 권한 정책
- `LEARNINGS.md`: 검증된 학습
- `CHANGELOG.md`: 사용자 영향 변경사항
- `HANDOFF.md`: 작업 인계 상태
